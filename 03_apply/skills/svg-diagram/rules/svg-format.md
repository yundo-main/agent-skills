# SVG 양식 규격 (메타프롬프트 — L3 리소스로 내장)

이 파일은 메타프롬프트적 요소가 스킬의 부품으로 내장된 사례다.
(양식만 정의하면 메타프롬프트 — 이처럼 실행 절차의 참조 리소스가 되면 스킬의 일부)

## 캔버스·구조
- `viewBox="0 0 1280 720"` 고정 (16:9), `width`·`height`·`role="img"` 명시
- 배경: 전체 rect `#f8fafc` + 상단 10px 바 `#1769aa`
- `<defs>`에 화살표 marker 정의 후 `marker-end="url(#...)"` 사용

## 팔레트·폰트
- ink `#122033` / muted `#516174` / line `#c9d5e1` / accent `#1769aa`
- 폰트: 시스템 스택만 (-apple-system, 'Noto Sans KR' 등) — 외부 폰트·CDN 금지

## 출력 제약
- `<svg>...</svg>` 블록만 출력 — 설명·주석 텍스트는 별도 문서로
- 외부 리소스·`<script>` 금지
