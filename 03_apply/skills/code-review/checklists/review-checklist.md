# 리뷰 체크리스트 (L3 리소스 — 본문에서 참조될 때만 로드)

## 보안 (critical 후보)
- [ ] 하드코딩된 키·토큰·비밀번호
- [ ] eval / exec / os.system 등 임의 코드 실행
- [ ] 검증 없는 사용자 입력의 경로·쿼리·명령어 사용

## 정확성 (major 후보)
- [ ] bare except / 예외 삼키기
- [ ] 열린 파일·커넥션 미해제
- [ ] 경계값(빈 입력, None, 0) 미처리

## 성능 (minor~major)
- [ ] 반복문 안의 불필요한 I/O·중복 계산
- [ ] 전체 리스트 대신 필요한 부분만 처리 가능한지

## 가독성 (minor)
- [ ] 의미 없는 변수명, 주석 없는 매직 넘버
- [ ] 한 함수가 두 가지 이상의 일을 하는지
