# SVG Diagram 절차

1. 요청에서 다이어그램의 대상·관계·메시지를 파악한다.
2. `rules/svg-format.md`의 양식 규격을 읽어 적용한다 — 규격 밖 출력은 재작성한다.
3. SVG를 파일로 저장하고 XML 파싱으로 검증한다.
4. PNG 등 렌더링 가능한 형식으로 변환해 결과를 첨부한다.

출력 규칙: 생성 코드는 `<svg>...</svg>` 블록만 — 설명 문구는 따로 적는다.
